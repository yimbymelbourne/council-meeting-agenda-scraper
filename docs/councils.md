# Council list

Every council this project tracks, with the meeting page to scrape and the
slug used for its scraper and fixtures.

**Scraper status is not recorded here.** It used to be, in three hand-edited
columns, and they drifted out of date — the table claimed councils were
"Functioning" while their fixtures held a single meeting and no minutes.
Status is now derived from the recorded fixtures instead:

```bash
poetry run python scripts/scorecard.py          # every council
poetry run python scripts/scorecard.py --gaps   # only what is unfinished
```

That reports meetings found, years covered, minutes coverage, and whether a
scraper is `complete`, `partial` or `broken` — computed from the fixtures, so
it cannot disagree with them.

To find out what platform a council runs before writing a parser:

```bash
poetry run python scripts/detect_platform.py <slug>
```
